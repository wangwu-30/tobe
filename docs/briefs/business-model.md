## 现状

- 本地 Electron 应用，用户自带 API key，无云端/账号/收费基础设施。
- Playbook / Workflow / Note 锁在本地，无法流通。
- "卖结果不卖时间"方向已确认，缺具体变现路径。

---

## 目标

1. 免费层足够好——不靠功能残缺逼付费，靠网络效应自然驱动。
2. 方法论流通但不泄露——使用者用到好方法，贡献者不失去壁垒。
3. 贡献者有真实经济回报——不是为爱发电。

## Workflow 云端运行

核心决策：**Workflow 存在云端，使用者只能调用，不能下载。**

```
使用者提交 Brief → 云端加载贡献者的 Workflow → 模型执行 → 返回 Result
```

使用者看到：说明、评分、使用次数、示例产出、额度消耗。
使用者看不到：步骤、约束、prompt、骨架。

与协议层映射：Brief = 目标 + 约束，Result = 交付物，Review = 评论修改。

对 `Method` 对象影响：新增 `visibility` 字段（`private` / `listed` / `published`）。

## 额度消耗与发布者定价

| 操作 | 默认额度消耗 |
|------|------------|
| 普通 AI 对话 | 1× |
| Workflow 调用 | 2×（默认） |

用户接受逻辑：自己试错 5 轮 = 5×，用好方法 1 次出结果 = 2×，更划算。

发布者可自主设置倍率：

| 倍率 | 场景 |
|------|------|
| 1×（免费推广） | 冷启动，发布者主动放弃返利换曝光，三方零额外成本 |
| 2×（标准） | 默认定价 |
| 3×（精品） | 头部高质量方法，品牌溢价 |

## 贡献返利

### V1：抵扣订阅

返利 = 每次 Workflow 被调用时，按模型消耗比例返还，**用于抵扣贡献者自己的订阅费**。

以 2× 标准定价为例，用户消耗 2 次额度（隐含 ¥0.39）的内部分配：

- 模型成本 ¥0.11
- 贡献者返利 ¥0.07
- 平台留存 ¥0.21

返利阶梯：

| 月被调用 | 月返利 | 体感 |
|---------|--------|------|
| <100 | ~¥7 | 一杯咖啡 |
| 500 | ~¥35 | 接近标准订阅费 |
| 2,000 | ~¥140 | 接近专业订阅费（≈免费用） |
| 10,000+ | ¥700+ | 溢出 → 触发 V2 |

### V2：可提现

当头部贡献者返利自然溢出订阅费时，上线提现能力。

### 设计原则

- 返利是贡献者**赚到的**，不是平台施舍的。标准和专业都有，不用返利卡升级。
- V1 不涉及支付牌照/税务，只做订阅减免。

---

## 防刷规则

- 仅付费用户的调用产生返利（免费 5 次试用不计）
- 实际 token 消耗低于阈值不计（Brief 为空/极短）
- 同一用户 + 同一 Workflow + Brief 相似度 >90% → 24h 内不重复计
- 单用户单 Workflow 每日上限 10 次
- 返利 90 天有效期，累积上限 ¥500（V2 上线后可提现溢出部分）

---

## 平台利润来源

不是模型差价，不是用户可见的"平台费"。是**订阅收入减去模型成本和返利后的留存**。

Workflow 调用时平台留存（¥0.21）> 普通对话时（¥0.085），因此 Workflow 生态越繁荣，平台越赚钱。

规模化预估（10,000 付费用户，模型批量折扣后）：毛利率 ~30%+。
